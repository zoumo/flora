# 分阶段实现

功能、修复和重构需要拆分时，在首次修改前使用本页。
当前 playbook 决定验收目标。主 Agent 负责从拆分到最终验收。

1. 核对已有规范、ticket 和验收证据。复用有效内容，只补缺口。
2. 按能单独验证的结果拆分工作。记录真实依赖、验收条件和负责人。
3. 有独立交付物且需要分工时才委派。并行写入使用隔离工作区。
4. 核对返回产物的版本和验证结果。按依赖顺序集成，失败时交回原负责人。
5. 在集成结果上核验用户要求的行为，交付最终证据。

只有后续工作必须依赖前序的独立验证结论时，才设置阶段验收。
写明依赖的产物、必验行为及后续工作必须等待的原因。
用户或仓库指定的审查照常执行。拆分本身不触发额外规划核对。

需要中断恢复时，在已有任务记录中保留产物位置、当前版本、执行者和剩余工作。
恢复时先核对实际状态，从首个未完成项继续。
