# 操作

## 职责

操作系统、平台或仓库状态，并按用户要求报告或持续跟进。
覆盖 skill 同步、PR、CI、工作项、文档平台和环境操作。

## 步骤

1. 确认目标、环境、权限和当前状态。
2. 优先找到并使用专用 CLI。
3. 执行用户要求的操作。
4. 用 CLI 或权威接口读回实际状态。
5. 报告变更、结果和未完成项。

请求分为 3 类：

- “查状态”执行一次读取并报告。
- “执行操作”完成操作并读回结果。
- “盯到结束”持续跟进终态。

按目标调用对应平台 skill。
持续跟进使用有界等待，保存恢复信息。
同类失败重复出现时先核对目标、权限和前置条件。

## 停止点

操作目标已达到，或目标已确认失败或阻塞。
持续任务按用户停止条件、期限或目标终态结束。
系统接受请求但尚未完成时，报告为已接受，不能记为完成。
