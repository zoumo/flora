# 简单修复

当前上下文负责完整任务，不委派实现。
不生成规范、ticket 或持久化 ticket 状态。
不强制独立 review。仓库规定的检查仍需执行。

## 步骤

1. 明确预期行为和完成证据。
   - 读取[完成证据](../references/completion-evidence.md)。
   - 说明本次修复的完成证据要求。
   - 修复前，记录同一场景的失败证据。
2. 准备任务工作区。
   - 调用 `flora-git-flow` 准备单任务工作区。资源负责人是当前上下文。
   - 记录基线和本次改动范围。
3. 完成最小修复。
4. 运行聚焦验证。
   - 重跑原失败场景。保留通过证据。
5. 检查 diff 和改动范围。
6. 报告修复结果与完成证据。
   - 输出原因、修复内容、验证结果和未完成项。
