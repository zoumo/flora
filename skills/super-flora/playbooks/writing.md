# 写作

## 职责

把已有信息交付成适合读者使用的文档、报告、说明、图表或演示产物。
写作流程不负责补做未要求的系统操作。

## 步骤

1. 明确读者、用途、来源和交付位置。
2. 组织内容，先写结论和关键事实。
3. 生成正文或目标文件。
4. 核对事实、术语、格式、引用和可读性。
5. 交付文件时，打开或渲染最终文件，核对呈现结果。
6. 报告产物位置、完成证据和未确认项。

中文遵循简明技术中文。
英文遵循仓库语言规则。
编写 skill 或 Agent 指令时使用 `skill-creator` 和 `writing-for-agents`。
图表、幻灯片和办公文档调用对应能力。

## 停止点

内容达到本次用途，目标产物可读取。
草稿不会自动发送、上传或发布。
用户要求外部发布时，转到操作流程完成授权范围内的发布和读回。
